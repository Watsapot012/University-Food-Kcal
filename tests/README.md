| `test_02_TC_HOME_02_ตัวชี้วัดสรุป.py` | **TC-HOME-02** | หน้าแรก (Home) | ตัวชี้วัดสรุป โหลดหน้าแรก | แสดงการ์ดจำนวนร้าน, จำนวนเมนู, ค่าเฉลี่ย kcal ถูกต้อง |
| `test_03_TC_REST_01_แสดงร้านค้า.py` | **TC-REST-01** | ร้านค้า (Restaurants) | แสดงรายชื่อร้าน เข้าแท็บร้านค้า | แสดงรายชื่อร้านค้าในมหาวิทยาลัยครบถ้วน พร้อมเวลาเปิด-ปิด |
| `test_04_TC_REST_02_กรองเมนูตามร้าน.py` | **TC-REST-02** | ร้านค้า (Restaurants) | กรองเมนูตามร้าน เลือกร้านป้าสมใจ | แสดงเฉพาะเมนูอาหารของร้านป้าสมใจเท่านั้น |
| `test_05_TC_FOOD_01_ค้นหาเมนูอาหาร.py` | **TC-FOOD-01** | รายการอาหาร (Food List) | ค้นหาชื่ออาหาร พิมพ์ "ต้มยำ" | กรองเหลือเฉพาะเมนูก๋วยเตี๋ยวต้มยำหมูน้ำใส |
| `test_06_TC_FOOD_02_กรองช่วงแคลอรี่.py` | **TC-FOOD-02** | รายการอาหาร (Food List) | กรองช่วง Kcal Min: 200, Max: 450 | แสดงเฉพาะอาหารที่แคลอรี่อยู่ในช่วง 200–450 kcal |
| `test_07_TC_CUST_02_ปรับแต่งเพิ่มไข่ดาว.py` | **TC-CUST-02** | ปรับแต่งอาหาร (Customizer) | ท็อปปิ้งไข่ดาว ติ๊กเลือก "+ไข่ดาว (+90 kcal)" | แคลอรี่คำนวณใหม่เป็น 640 kcal ทันทีแบบ Real-time |

| `test_09_TC_PROF_01_คำนวณBMR_TDEE.py` | **TC-PROF-01** | โปรไฟล์ (Profile) | คำนวณ BMR & TDEE ชาย นน.65, สส.175, อายุ 21 | BMR = 1,644 kcal และ TDEE = 2,548 kcal (สูตร Mifflin-St Jeor) |
| `test_10_TC_AUTH_01_เข้าสู่ระบบ.py` | **TC-AUTH-01** | เข้าสู่ระบบ (Auth Modal) | Login สำเร็จ student@npru.ac.th / รหัสถูกต้อง | เข้าสู่ระบบสำเร็จ ได้รับ Token และแสดงชื่อผู้ใช้ที่ Navbar |

## 🚀 วิธีการสั่งรันการทดสอบ

### 1. รันรวมทุกเคส (10 Test Cases ต่อเนื่อง):
```bash
python tests/test_portal_10_cases.py
# หรือผ่าน npm
npm run test:suite
```

### 2. รันแยกรายไฟล์เฉพาะเคสที่ต้องการตรวจสอบโค้ด:
```bash
# ทดสอบค้นหาด่วนหน้าแรก
python tests/test_01_TC_HOME_01_ค้นหาด่วน.py

# ทดสอบตัวชี้วัดสรุปหน้าแรก
python tests/test_02_TC_HOME_02_ตัวชี้วัดสรุป.py

# ทดสอบแสดงรายชื่อร้านค้า
python tests/test_03_TC_REST_01_แสดงร้านค้า.py

# ทดสอบกรองเมนูตามร้านค้า
python tests/test_04_TC_REST_02_กรองเมนูตามร้าน.py

# ทดสอบค้นหาเมนูอาหาร
python tests/test_05_TC_FOOD_01_ค้นหาเมนูอาหาร.py

# ทดสอบกรองช่วงแคลอรี่
python tests/test_06_TC_FOOD_02_กรองช่วงแคลอรี่.py

# ทดสอบปรับแต่งเพิ่มไข่ดาว
python tests/test_07_TC_CUST_02_ปรับแต่งเพิ่มไข่ดาว.py

# ทดสอบบันทึกมื้ออาหารลงไดอารี่
python tests/test_08_TC_DASH_02_บันทึกมื้ออาหาร.py

# ทดสอบคำนวณ BMR & TDEE
python tests/test_09_TC_PROF_01_คำนวณBMR_TDEE.py

# ทดสอบเข้าสู่ระบบ
python tests/test_10_TC_AUTH_01_เข้าสู่ระบบ.py
```
