## ⚙️ เตรียมสภาพแวดล้อมก่อนรัน

รันจากโฟลเดอร์หลักของโปรเจกต์เพื่อติดตั้ง dependencies ของเว็บแอป:
```bash
npm ci
```

หากต้องการรันทดสอบด้วย Selenium และเปิด Chrome จริง ให้ติดตั้ง dependencies ของ Python ด้วย:
```bash
python -m pip install -r tests/requirements.txt
```

## 🚀 วิธีการสั่งรันการทดสอบ

### 1. รันรวมทุกเคส (10 Test Cases ต่อเนื่อง):
```bash
python tests/test_portal_10_cases.py
# หรือผ่าน npm
npm run test:suite
```
เมื่อไม่ได้กำหนด `APP_URL` ตัวรันจะเปิดแอปจาก source ใน checkout นี้ให้อัตโนมัติ
หากต้องการทดสอบกับแอปที่เปิดอยู่แล้ว ให้กำหนด `APP_URL` ก่อนรัน

### 2. รันแยกรายไฟล์เฉพาะเคสที่ต้องการตรวจสอบโค้ด:
```bash
# ทดสอบค้นหาด่วนหน้าแรก
python tests/test_01_TC_HOME_01_ค้นหาด่วน.py

# ทดสอบตัวชี้วัดสรุปหน้าแรก
python tests/test_02_TC_HOME_02_ตัวชี้วัดสรุป.py

# ทดสอบแสดงรายชื่อร้านค้า
python tests/test_03_TC_REST_01_แสดงร้านค้า.py

# ทดสอบกรองเมนูตามร้านค้า
python tests/test_04_TC_REST_02_กรองเมนูตามร้าน.py

# ทดสอบค้นหาเมนูอาหาร
python tests/test_05_TC_FOOD_01_ค้นหาเมนูอาหาร.py

# ทดสอบกรองช่วงแคลอรี่
python tests/test_06_TC_FOOD_02_กรองช่วงแคลอรี่.py

# ทดสอบปรับแต่งเพิ่มไข่ดาว
python tests/test_07_TC_CUST_02_ปรับแต่งเพิ่มไข่ดาว.py

# ทดสอบบันทึกมื้ออาหารลงไดอารี่
python tests/test_08_TC_DASH_02_บันทึกมื้ออาหาร.py

# ทดสอบคำนวณ BMR & TDEE
python tests/test_09_TC_PROF_01_คำนวณBMR_TDEE.py

# ทดสอบเข้าสู่ระบบ
python tests/test_10_TC_AUTH_01_เข้าสู่ระบบ.py
```

## 🌐 การทดสอบแบบเปิด Google Chrome จริงบนหน้าจอ (GUI End-to-End ไม่ใช่แค่ Unit Test)

บน Windows การรันทดสอบจากเทอร์มินัลจะเปิดหน้าต่าง **Google Chrome** และทดสอบหน้าเว็บจริง หากต้องการบังคับเปิด Chrome ให้เพิ่ม `--browser`:

```bash
# เปิดเบราว์เซอร์ Chrome จริงเพื่อทดสอบค้นหาด่วน
python tests/test_01_TC_HOME_01_ค้นหาด่วน.py --browser

# รันทุกเคสและค้างหน้า Chrome หลังแต่ละเคส จนกว่าจะกด Enter
python tests/test_01_TC_HOME_01_ค้นหาด่วน.py --browser --keep-open

# รันครบทั้ง 10 เคส และค้างหน้า Chrome หลังแต่ละเคส
python tests/test_portal_10_cases.py --browser --keep-open

# หรือเปิดเบราว์เซอร์ทดสอบครบทั้ง 10 เคสโดยไม่ค้างหน้าจอ
python tests/test_portal_10_cases.py --browser
```

เมื่อรันจากเทอร์มินัลแบบโต้ตอบ Chrome จะค้างหลังแสดงผลแต่ละเคสโดยอัตโนมัติ กด Enter เพื่อปิดและไปต่อ หากต้องการรันต่อเนื่องโดยไม่หยุด ให้เพิ่ม `--no-keep-open` ตัวรันชุดรวมจะแสดงรายละเอียดและผล PASS/FAIL ของทุกเคสในเทอร์มินัลทันที
